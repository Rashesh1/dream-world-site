# Dream World Website — Project Root

Everything for the Dream World (Dehradun furniture brand) website lives here.

## Folders
| Folder | Contents |
|---|---|
| `01_catalog_raw/` | Original WhatsApp export (51 images + `_chat.txt`). Untouched source. |
| `02_assets_optimized/` | Catalog images renamed by category: `beds/`, `sofas/`, `loungers/`, `tables/`, `brand/` (logo). |
