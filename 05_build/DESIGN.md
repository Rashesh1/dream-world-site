# Dream World — Design System

**Genre:** editorial-luxury · **Tone:** premium, warm, trustworthy · **Stack:** vanilla HTML/CSS/JS (DRY shell) + Sveltia git-CMS + Netlify. Motion added for premium feel; no framework.

## Tokens (`assets/css/tokens.css`)
- **Paper:** ivory `oklch(95.5% .012 85)` (#F6F1E9) — never pure white.
- **Ink:** midnight indigo `oklch(26% .035 265)` (#1C2438).
- **Accent:** brass `oklch(63% .075 74)` (#B08D57) — ties to the gold logo.
- **Support:** soft sage; near-black indigo `--color-night` for logo pill / craft band / footer.
- **Type:** Fraunces (display serif) + Manrope (body). All headings roman (no italic headers).
- **Space:** 4pt scale. **Radius:** 14px. **Motion:** 3 named easings, reveal-on-scroll only, `transform`/`opacity` only, reduced-motion honored.

## Structure
- **Nav:** N1b masthead — logo pill (gold-gradient "DREAM WORLD" on night) · category links · Call + WhatsApp CTA. Sticky, blur, border on scroll.
- **Home rhythm:** Hero (headline + product visual + made-to-order meta) → trust strip → category grid (4) → catalogue (filter chips + 34 cards) → craft band (dark, why-us) → distributor teaser → statement footer. Floating WhatsApp everywhere.
- **Product card:** square image · category · name · price "onwards · made to order" · WhatsApp Enquire (deep-link prefilled with name+SKU+price).
